# Fision180

Modelado 3D paramétrico para macOS.

## Descarga

Descargue la última versión en [Releases](https://github.com/Kativin/Fision180/releases/latest):

- `Fision180-X.Y.Z-mac-arm64.dmg`: Mac con Apple Silicon (M1, M2, M3…)
- `Fision180-X.Y.Z-mac-x64.dmg`: Mac con procesador Intel

Abra el DMG y arrastre Fision180 a Aplicaciones. La app avisa sola cuando hay una versión nueva.
